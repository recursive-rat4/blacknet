# Environment Variables

## Directories

- `BLACKNET_CONFIGDIR` configuration files.
- `BLACKNET_DATADIR` data files such as blocks and wallets.
- `BLACKNET_STATEDIR` state files such as logs.

## Logging

- `BLACKNET_LOGLEVEL` possible values: "trace", "debug", "info", "warn", "error", "critical".
- `RUST_LIB_BACKTRACE` possible values: "0", "1".

## Test

- `BLACKNET_MODE` possible values: "MainNet" or "RegTest".
